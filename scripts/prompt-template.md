# 播客笔记整理提示词模板

## 使用方法

将以下内容复制给 AI，替换 【】 中的内容：

---

请帮我整理以下播客/视频的笔记：

【内容】
[将飞书妙记导出的文字内容粘贴在这里]

【整理要求】
1. 提炼核心要点（3-5个）
2. 提取关键概念和术语，并给出解释
3. 整理成结构化的大纲
4. 生成行动清单（你可以立即执行的行动）
5. 如有需要，制作思维导图（用 ASCII 或 Markdown 格式）

【背景】
[可选：这是关于XX主题的内容]
[可选：你的学习目标是XX]
[可选：你希望重点关注XX方面]

---

## 示例

请帮我整理以下播客的笔记：

【内容】
[粘贴文字内容...]

【整理要求】
1. 提炼核心要点
2. 提取关键概念
3. 整理成结构化大纲
4. 生成行动清单

【背景】
这是一期关于产品经理职业发展的播客，我想转行做 PM，想了解需要准备什么技能。

---

## 输出示例

### 核心要点
1. ...
2. ...
3. ...

### 关键概念
| 术语 | 解释 |
|-----|------|
| XXX | ... |

### 结构化大纲
1. 章节一
   - 要点1
   - 要点2
2. 章节二
   ...

### 行动清单
- [ ] 行动1
- [ ] 行动2
- [ ] 行动3

### 思维导图
```
      主题
      ├── 分支1
      │   ├── 要点A
      │   └── 要点B
      └── 分支2
          ├── 要点C
          └── 要点D
```
